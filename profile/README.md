Open-source software, built to be owned: apps and tools that run on your own machines and keep your data there.

| Project | What it is |
| --- | --- |
| [Bragi](https://github.com/radar-hooves/bragi) | The desktop player for your own Jellyfin or OpenSubsonic music server, browsable even offline |
| [Thoth](https://github.com/radar-hooves/thoth) | Private, offline voice transcription for macOS and Linux: press a key, speak, and the text lands at your cursor |
| [supacrawl](https://github.com/radar-hooves/supacrawl) | Zero-infrastructure web scraping for the terminal and AI assistants |
| [app-factory](https://github.com/radar-hooves/app-factory) | Copier skeletons and versioned kits that every app is stamped from, in every language |

Contributions are welcome: read [CONTRIBUTING](https://github.com/radar-hooves/.github/blob/main/CONTRIBUTING.md) first.
