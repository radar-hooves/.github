# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, never in a public issue or pull request:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what an attacker could do with it.

Only the maintainers can read the report. You will hear back within a week, and we will agree a disclosure date with you before anything is published.

## Supported versions

Fixes go into the latest release. Desktop apps that update themselves receive them automatically; for the others, install the latest release.
